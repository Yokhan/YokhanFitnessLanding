# YokhanFitness Content And Asset Table

Goal: close the gap between the current program landing and a stronger Oura-like sales page.

## Priority Content

| Priority | Page section | Needed content | Description | Why it matters |
|---|---|---|---|---|
| P0 | Hero | Real hero media | 1 horizontal photo/video of Igor or training setup, not stock. Ideally warm light, body in motion, clear environment. | Oura sells with the actual product in the first viewport. We need the real person/service signal immediately. |
| P0 | Hero | One-line positioning | Final wording for the core promise: who this is for, what changes, why now. | Current hero is usable, but still generic without your sharper market position. |
| P0 | Program cards | Final program package names | Confirm names: `Тело атлета`, `Здоровая спина`, `Топ ягодицы`, `Похудеть навсегда`, etc. | Names become campaign hooks, bot branches, and content buckets. |
| P0 | Program cards | Program outcomes | For each program: main visible outcome, secondary health outcome, emotional/social payoff. | Cards should sell the future, not just list exercises. |
| P0 | Bot path | Start parameter routing | Define behavior for `landing_programs`, `landing_men`, `landing_women`, `landing_final`. | Without routing we lose source/segment tracking. |
| P0 | Offer | Pricing/package decision | 4/8/12 sessions per month, exact payment model, what support is included. | Oura makes purchase terms explicit. We need the same clarity before traffic. |

## Proof And Trust

| Priority | Page section | Needed content | Description | Why it matters |
|---|---|---|---|---|
| P1 | Proof | 3 client cases | Before state, constraints, program used, timeline, result, quote, permission level. | Replaces abstract credibility with concrete human proof. |
| P1 | Proof | Before/after assets | Photos, screenshots, measurements, training logs, or clothing-fit evidence where ethical and permitted. | Fitness buyers need proof that the program changes visible reality. |
| P1 | Method | Trainer proof | Diploma/certification photo, relevant bio, personal transformation story, training philosophy. | Oura has science/engineering credibility. Here the trust anchor is Igor plus method. |
| P1 | Method | Evidence notes | Short source-backed notes: strength training, back pain prevention, depression symptom reduction, weight management. | Allows stronger claims without sounding like medical spam. |
| P1 | Safety | Red flag policy | Clear rule for pain, injuries, medical limits, and when the user goes to doctor first. | Protects user and brand. Also increases authority. |
