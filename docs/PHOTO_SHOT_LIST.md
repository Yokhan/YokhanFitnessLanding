# YokhanFitness Photo Shot List

Goal: give the multi-page landing the same tangible product signal that Oura gets from real ring photography.

## Capture Rules

| Rule | Requirement |
|---|---|
| Format | Shoot vertical and horizontal for every P0 scene. |
| Quality | Use phone main camera, clean lens, no aggressive filters, no screenshots from video. |
| Resolution | Minimum 3000px on the long side. Keep originals. |
| Light | Soft daylight near window or warm gym light. Avoid ceiling-only light. |
| Background | Clean home/gym setting. No clutter, trash, random screens, private data. |
| Composition | Leave empty space on one side for text overlays. |
| Clothing | Simple dark/neutral sport clothes. No loud logos. |
| Consent | Any client/model photo needs explicit permission for landing/social use. |
| Delivery | Put originals in `assets/photo/raw/`; selected exports in `assets/photo/web/`. |

## What To Avoid

- Stock-like dark gym photos with no real Igor/service signal.
- Sexualized women-program photos.
- Medical claims in image text.
- Screenshots with private names, phones, chats, tokens, payments.
- Overedited HDR, heavy blur, face smoothing, fake luxury.
